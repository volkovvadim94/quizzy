# Quizzy локальный деплой

> Бэкенд и фронтенд теперь настроены на домен `https://quizzy.myddns.me`, который указывает на ваш сервер (`109.207.81.60`). В файлах конфигурации прописаны только те переменные, которые нужны приложению, чтобы Telegram-авторизация и API работали из коробки.

## 1. Бэкенд (`/backend`)

- `.env` уже содержит:

  ```
  PORT=5001
  FRONTEND_URL=https://quizzy.myddns.me
  TELEGRAM_BOT_TOKEN=<ваш токен>
  ```

- Старт локально: `cd backend && npm install && npm run dev` (или `npm start` для прод-режима). Сервер слушает порт `5001`.
- При работе через домен прокиньте 80/443 → reverse-proxy (nginx/traefik/IIS) который:
  1. Отдаёт собранный фронтенд.
  2. Проксирует `/api` и `/socket.io` на `http://127.0.0.1:5001`.
- Для HTTPS используйте уже выпущенный сертификат `quizzy.myddns.me` (через win-acme).

## 2. Фронтенд (`/frontend`)

- Есть два файла переменных:
  - `.env` — для `npm run dev`.
  - `.env.production` — под `npm run build`.
- Оба содержат:

  ```
  VITE_API_URL=https://quizzy.myddns.me/api
  VITE_TELEGRAM_BOT_ID=8518474305
  ```

- В `src/utils/api.js` используется `VITE_API_URL`, поэтому фронт всегда бьёт по домену. Если хотите тестить чисто локально, временно поставьте `VITE_API_URL=http://localhost:5001/api`.
- Локальный запуск: `cd frontend && npm install && npm run dev` (Vite на `http://localhost:5173`). Для работы Telegram ID должен совпадать с ботом, который подключён на бэкенд.

## 3. Проверка

1. Запустите бэкенд (`npm run dev`) и убедитесь, что `http://localhost:5001/api/health` отвечает.
2. Запустите фронт (`npm run dev`) и проверьте авторизацию через Telegram — ошибок `Не задан VITE_TELEGRAM_BОТ_ID` больше не будет, потому что переменная берётся из `.env`.
3. После сборки (`npm run build && npm run preview`) убедитесь, что в сети запросы уходят на `https://quizzy.myddns.me/api`.

Этого достаточно, чтобы поднять сервис локально и затем пробросить его наружу через ваш домен с TLS. Если нужны дополнительные профили (.env.staging и т.п.) — создайте их, скопировав текущее содержимое и изменив лишь URL.
